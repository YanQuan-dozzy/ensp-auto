# 界面与视觉规格

## 1. 设计立场

| 立场 | 说明 |
|---|---|
| **深色为主，可切浅色** | 终端天生深色，深色壳与其融合最自然；长时间盯盘护眼；拓扑的状态色在深底上表达力更强。浅色作为可选项，服务于投屏与教学场景。 |
| **工程感，不是消费级** | 信息密度高于普通 SaaS。用户是网络工程师，能接受更多同时可见的信息，反感大留白与装饰性动效。 |
| **代理是主角** | AI 面板常驻，不是侧边抽屉。整个产品的主张就是「说目标，不看过程」，「看过程」的能力必须随时在手边。 |
| **克制** | 无渐变、无毛玻璃、无发光、无插画。层级靠留白、描边与极少量阴影建立。 |
| **状态永远可见** | 设备连没连、代理跑到哪步、有没有等待确认 —— 任何时刻不靠猜。 |

## 2. 三栏布局

```

│ 顶栏 44px   ensp-auto            端口 2000–2050  主题  设置       │
├──────────┬────────────────────────────────────┬──────────────────┤
│          │  tab 36px                          │                  │
│  左栏    │  [ 拓扑画布 ] [ 终端 ]              │     右栏         │
│  240px   │  ─────────────────────────────     │     380px        │
│          │                                    │                  │
│ 设备树   │            主舞台                  │   AI 面板        │
│          │                                    │                  │
│ 扫描     │  · 拓扑：React Flow 画布            │  消息流          │
│ 端口范围 │  · 终端：xterm.js                  │  计划卡          │
│ ───────  │                                    │  工具调用卡      │

├──────────┴────────────────────────────────────┴──────────────────┤
```

### 2.1 尺寸规格

| 区域 | 默认 | 可调范围 | 行为 |
|---|---|---|---|
| 顶栏 | 44px | — | 固定 |
| 左栏（设备树） | 240px | 180–360px | 可拖拽调宽，可折叠至 0 |
| 中栏（主舞台） | `minmax(0, 1fr)` | — | 弹性 |
| 右栏（AI 面板） | 380px | 320–560px | 可拖拽调宽，可折叠至 0 |
| 状态栏 | 24px | — | 固定，可隐藏 |

拖拽分隔条宽 4px，hover 时变为 `--accent`，光标 `col-resize`。
面板宽度持久化到设置。

### 2.2 响应式策略

| 视口宽度 | 行为 |
|---|---|
| ≥ 1280px | 三栏全展开 |
| 1024–1280px | 右栏默认折叠为底部输入条；点击展开为覆盖层 |
| < 1024px | 仅中栏；左右栏变抽屉，从边缘滑出 |

### 2.3 折叠态

- **左栏折叠**：顶栏出现设备图标 + 已连接数量徽标，点击展开抽屉。
- **右栏折叠**：底部保留一条输入条（代理仍然随时可用），点击展开完整面板。
  折叠态下若有任务在跑，输入条显示进度点与中断按钮 —— 折叠不等于失去控制。

## 5. 各区域交互细节

### 5.1 左栏 · 设备树

- **扫描**：顶部一行 —— 端口范围输入（两个 4 位数字输入框）+ 「扫描」按钮。
  扫描中按钮变为「停止（已扫 12/51）」，同时列表区顶部显示细进度条。
- **设备项**：状态点在左，名称居中偏左，端口号 `--text-xs` `--text-muted` 在名称下方。
  已连接的在名称右侧显示 `--success` 的「已连接」chip。
- **命名**：悬停名称出现铅笔图标，点击原地变输入框（不弹窗），Enter 保存、Esc 取消。
- **断开**：悬停设备项右侧出现断开图标，点击即断（无二次确认 —— 断开比连接安全）。
- **排序**：已连接优先，其余按端口升序。
- **空态**：居中提示「设置端口范围后点击扫描」。

### 5.2 中栏 · 主舞台

**tab 内容**

- **拓扑画布**（v0.3）：React Flow 画布，深色网格背景（`--bg-base` + 极淡网格线）。
  节点为圆角矩形，设备类型用左侧色条区分，链路状态用连线颜色（`--status-up` / `--status-down`）表达。
  节点 hover 显示设备名与 IP，点击聚焦到左栏对应设备。
- **终端**：xterm 容器，工具条显示「设备名 · 当前视图」（视图用 chip 标注，如 `[系统视图]`）。
  多设备时工具条左侧有设备切换下拉，避免 tab 频繁切换。

**终端细节（决定成败的地方）**

```ts
new Terminal({
  fontFamily: 'var(--font-mono) 实际值，需 JS 读取',  // 必须含 CJK 等宽字体回退
  fontSize: 13,
  lineHeight: 1.4,
  cursorBlink: true,
  convertEol: false,        // 设备输出自带换行，不做转换
  scrollback: 10000,
  theme: TERMINAL_THEME,    // 由 CSS 变量计算得出，见 §6
});
```

- **中文对齐**：等宽字体必须包含 CJK 回退，否则中文回显会错位。
  这是验收项「浅色主题无残留深色块」之外的隐藏验收点，实现后需专门目视核对。
- **代理命令标注**：代理下发的命令在终端中以 `--agent` 色加前缀 `⟨agent⟩` 显示，
  与用户手输的命令明确区分，同时在队列中排在其后。
- **队列提示**：若代理正在执行，用户敲的命令入队，终端顶部出现
  `队列中 2 条，等待中…` 的 `--status-pending` 提示条。

### 5.3 右栏 · AI 面板

**消息流**

- 用户消息：右对齐，`--bg-active` 底，圆角 `--radius-md`。
- 代理文本：左对齐，无底色，左侧 2px `--agent` 竖线。流式输出时末尾有闪烁光标。
- 计划卡：出现在代理开始执行前，步骤状态实时更新。
- 工具调用卡：每次调用一张。折叠态一行（工具名 · 设备 · 耗时 · 状态图标），
  展开可见参数与原始回显。失败时自动展开并显示错误原文。
- 结束语：任务完成时显示一行摘要 —— 用时、工具调用次数、变更/快照数量。

**输入区**

- 多行自适应（1–6 行），`--radius-md`，`Enter` 发送、`Shift+Enter` 换行。
- 代理执行中：输入框不锁定，消息进入队列并显示「队列中 N 条」小标。
- 左下角显示当前模型名，点击弹出模型切换。
- 未配置模型时，输入区替换为配置引导卡片。

**闸门（GateDialog）**

全屏半透明遮罩 + 居中对话框，这是整个 UI 唯一允许打断用户的操作：

```
┌──────────────────────────────────────────┐
│ 危险操作确认                              │
│ ──────────────────────────────────────── │
│ 设备      core-sw-1 (127.0.0.1:2008)     │
│ 命令      reset saved-configuration      │
│ 后果      将清空设备启动配置，重启后配置丢失 │
│ ──────────────────────────────────────── │
│ 可用快照  是（3 分钟前，4.2 KB）           │
│                                          │
│              [ 拒绝 ]    [ 确认执行 ]     │
└──────────────────────────────────────────┘
```

「可用快照」一行是刻意保留的 —— 它让用户在有安全网时更敢批准，
在没有安全网时本能地更谨慎。

### 5.4 状态栏

一行 `--text-xs` `--text-muted`，分隔符为 `·`：

```
已连接 3 · 队列 0 · 模型 deepseek-chat · 最近任务 2.4s
```

**不做进度百分比、不做图表** —— 状态栏只回答「现在能不能用」。

## 6. 双主题实现

### 6.1 CSS 变量层

```css
:root, html[data-theme='dark']  { /* 深色令牌 */ }
html[data-theme='light']        { /* 浅色令牌 */ }
```

切换主题 = 改 `document.documentElement.dataset.theme`，其余全部自动生效。

### 6.2 三处必须手动同步的地方

CSS 变量能覆盖 90% 的界面，但有三处是 JS 渲染的，**必须显式同步**，
否则会出现「切到浅色后终端还是黑的」这类残留：

| 目标 | 原因 | 做法 |
|---|---|---|
| **xterm.js** | 主题通过 `setOption('theme', ...)` 传入，不读 CSS | 主题变化时从 `getComputedStyle` 读取令牌值，组装 `ITheme` 后 `setOption` |
| **React Flow** | 节点/连线色通过 props 传入 | 把令牌值放进 React context，主题变化时重新计算 nodes/edges 的 style |
| **原生滚动条** | 需 `color-scheme` | 同步设置 `document.documentElement.style.colorScheme` |

主题选择持久化到设置；首次启动跟随系统（`prefers-color-scheme`），
用户手动切换后以用户选择为准。

## 7. 状态设计

| 状态 | 呈现 |
|---|---|
| 设备列表空 | 居中：图标 + 「设置端口范围后点击扫描」+ 「扫描」按钮 |
| 扫描中 | 按钮变「停止（已扫 12/51）」+ 列表区顶部细进度条 + 已发现项实时插入 |
| 连接中 | 设备项状态点 `pulse`，chip 显示「连接中」 |
| 连接失败 | 设备项描边变 `--danger`，chip 显示「失败」，hover 显示原因 |
| 已断开（异常） | 设备项置灰，右侧出现「重连」按钮 |
| 代理空闲 | 输入框占位符：「描述实验目标，例如：在三台路由器上跑通 OSPF」 |
| 代理运行中 | 面板顶部细进度条 + 「运行中」标 + 中断按钮；输入框可继续输入（入队） |
| 等待闸门 | 全局遮罩，不可忽略；状态栏显示「等待确认」 |
| 未配置模型 | AI 输入区替换为配置引导卡片，主按钮「配置模型」 |
| 快照缺失 | 需要写操作时，工具卡显示「正在采集快照…」，失败则红字提示并阻止变更 |

## 9. 无障碍

- 所有交互元素可 Tab 聚焦，焦点环用 `--accent`，不得用 `outline: none` 直接去除。
- **状态不能只靠颜色表达**：链路 up/down 除颜色外必须带文字或图形差异
  （否则色觉障碍用户无法区分，且深浅主题下颜色语义会变化）。
- 正文对比度 ≥ 4.5:1，次要文本 ≥ 3:1。
- 模态（GateDialog）必须做焦点陷阱，Esc 等价于「拒绝」。
- 遵守 `prefers-reduced-motion`，关闭 `pulse` 与过渡动画。
